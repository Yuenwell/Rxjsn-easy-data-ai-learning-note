# 学有所记 · 学习进度看板

一个无需安装依赖、可离线打开的个人学习工具。管理任务、记录文字与截图，再按任务导出适合放入 GitHub 的 Markdown 笔记。

## 快速开始

1. 下载本仓库 ZIP 并解压，或通过 Git 克隆仓库。
2. 用 Edge、Chrome 等现代浏览器打开 `tools/learning-dashboard/index.html`。
3. 打开任务记录进度，在“学习日志”创建自己的图文记录。

浏览器访问 GitHub 文件页面只会看到源码；需要先下载文件，保留本目录的文件结构，再打开本地 HTML。无需 Node.js、Python 或后端服务。

## 功能

- 任务进度、截止时间、北京时间倒计时与独立打卡记录。
- 任务笔记与可自行填写的参考来源，支持 Markdown 表格。
- 自定义日志小标题、任务归属、学习日期与时长。
- 上传或粘贴 PNG/JPG/WebP 截图，预览、放大与删除。
- 按任务导出图文 ZIP，包含 `README.md` 与相对路径的 `images/`。
- 单任务导出：一级任务标题、二级记录标题；全部导出：按任务分组。
- 导出保留普通文字换行，保护代码块、表格与标题格式。
- JSON 完整备份与恢复，以及多窗口冲突提示。

## 数据保存在哪里

本工具不附带任何个人进度、笔记、用户截图或备份。首次打开为零进度；页面中的课表只是示例配置。

你的输入保存在当前浏览器当前页面对应的 `localStorage` 中，键名为 `learning-dashboard.<courseId>.v1`。代码没有上传、遥测或云同步功能；仅在点击课程链接时访问对应外部网站。

同一路径用同一浏览器打开可继续记录。文件路径变化、无痕浏览、清理浏览器数据或更换浏览器，可能使原记录不可见。请定期导出 JSON；换环境后手动导入。下载的备份和图文笔记属于你自己，公开提交前自行检查。

截图每条最多 6 张，自动压缩为 JPEG；总图片编码限额约 2 MB。适合少量学习截图，原始高清图请另存。遇到保存失败提示时，当前内存内容仍可导出，关闭前先备份。

## 导出与公开发布

1. 保存日志时选择正确的关联任务。
2. 在“学习日志”选择导出范围，例如 Task01。
3. 点击“导出图文笔记 ZIP”，解压。
4. 检查文字、截图与参考来源，保持 `README.md` 和 `images/` 的相对位置，再提交到自己的成果仓库。

参考来源由用户填写；字段留空则不会自动补充来源。请对引用或改编的材料提供真实来源，并遵守对应许可。公开发布源码不会把浏览器中的学习记录一起带走；不要另行上传包含私人信息的备份。

## 更换课程或课表

编辑 `data.js`：

| 字段 | 用途 |
| --- | --- |
| `chapters` | 学习项编号、名称、分类与阅读链接 |
| `tasks` | 任务编号、标题、天数、截止时间、学习项列表 |
| `courseId` | 课程标识；更换课程时使用新的标识，隔离浏览器进度 |
| `start` / `timezone` | 示例开始日期与时间说明 |

当前默认示例是 Easy Data × AI 的 2026 年 11 月共学任务。任务和章节列表可修改；界面有少量“9 个任务”等与示例数量对应的文案，改变任务数时需同步调整 `index.html`、`app.js` 中这些文案。时间计算当前采用北京时间，修改 `timezone` 字段不会自动更改 UTC+8 的计算逻辑。

默认日期仅供示例，实际课程范围、打卡时间与验收要求请以自己参加课程的通知为准。课程阅读链接可能随上游更新。

## 目录

```text
learning-dashboard/
├── index.html
├── styles.css
├── data.js          # 示例课表，不含用户记录
├── core.js          # 进度、日期、备份校验
├── app.js           # 页面交互与本地保存
├── images.js        # 图片压缩与 ZIP 导出
├── markdown.js      # 导出换行处理
├── tests/           # 使用合成输入的便携逻辑测试
├── .gitignore
├── README.md
└── LICENSE
```

如果已安装 Node.js，可以运行不依赖第三方库的逻辑测试：

```text
node --test tests/core.test.cjs tests/markdown.test.cjs
```

测试不含用户真实数据。发布前另在隔离 Edge 浏览器中检查了空白初始状态、记录保存与重开、截图与导出、本地路径隔离及移动端布局。浏览器检查环境不属于使用本工具的依赖。
