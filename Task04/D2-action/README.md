# D2 课后行动 · 用自己的电子资料比较三路检索

实验日期为 2026-11-25。使用自己的电子器件手册、应用指南和教材，共 139 份 PDF、38,463 个片段，已导入本机 seekdb v1.4.1.0。

## 实验设置

同一批 10 道问题在同一个集合上分别跑三种检索。

| 检索 | 输入与排序 |
| --- | --- |
| 纯向量 | 用本地 E5 编码完整问题，按向量相似度取前 20 条。 |
| 纯全文 | 从问题选出关键词，按 seekdb 的全文检索取前 20 条。 |
| 混合 | 两路各取前 20 条，使用 RRF 融合，`rank_constant` 为 60。 |

先看每路前 3 条是否包含能直接回答问题的证据。型号题同时核对手册和参数，原文证据按 PDF 页码定位。

## 向量命中，全文未把证据排进前 3

Q7 用「让采样结果不稳定」描述现象，相关教材用的是「基准源的瞬态响应」「电荷存储」和「去耦」。向量第 2 条找到了第 395 页，里面说明 SAR ADC 转换期间参考端会动态取电，容量不足的旁路电容可能使参考电压波动。全文前 3 条提到了采样或稳定性，能直接解释这个机制的片段排在向量一路。RRF 将这条证据排到了第 14，说明语义较强的候选也可能在融合中降名次。

Q2 还有一种情况。全文的前 3 条都来自 AD8310 手册，但返回的片段只显示型号。向量第 1 条直接给出 440 MHz。找到手册和定位到具体参数是两次不同的检查。

## 全文命中，向量漏掉或排错

Q3 的全文第 3 条找到了 TPS7A4501 的 1.21 V，向量的前 3 条排进了别的 ADC 手册。Q5 也类似。搜 `OPA690` 时，全文第 3 条给出单位增益下的 500 MHz，向量前 3 条排的是通用运放资料。

Q8 展示了精确数字的作用。全文用 `440 MHz` 搜到 AD8310 手册第 1 页并排在首位。向量前 3 条偏向对数放大器原理，混合检索补回了明确的型号，排在第 2。

## 两路结合后才进前 3 的例子

Q10 的向量第 1 条解释的是输出偏置，全文第 1 条写的是示波器交流耦合。真正回答这道放大器问题的片段是 TI 运放应用指南第 68 页。**同一条证据在向量里排第 4、在全文里排第 7，RRF 融合后升到第 2。** 按只看前 3 条的标准，两路融合才把这条证据送进上下文。

## 实验结论

概念题可以先用向量找同义表达，型号、单位和数字适合同时走全文。查精确器件参数时，先核对型号和手册，再读对应页的规格行。Q3 和 Q5 表明，直接做等权 RRF 也可能把有用的型号证据挤出前 3。Q10 则说明，两路共同找到的中等名次证据有机会被融合排到前面。这 10 道题用于比较典型情况，排序结论适用于本次语料和问法。
